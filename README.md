## Research orientation

I study how **Data, Information, Knowledge, Wisdom and Purpose (DIKWP)** can be represented as distinct but transformable semantic resources—and how each transformation can remain visible, testable, revisable and accountable.

The originating research line systematically extends knowledge graphs into **typed, computable DIKW and DIKWP resource graphs**. Public patents from 2017 onward show the path from linked D/I/K/W graphs to intent-driven typed-resource derivation and Purpose-resource graphs; Hainan University records the team's 2020 Wu Wenjun AI Award for “DIKW graphical extension and modelling.” [Institutional record →](https://en.hainanu.edu.cn/info/1151/2981.htm)

**Working loop:** D → I → K → W → P → authorized action → evidence → revision.

> **Claim boundary:** public code and repository descriptions establish scope, inspectability and self-described implementation status. They do not alone establish external validation, clinical or financial effectiveness, commercial adoption, production fitness, phenomenal consciousness, institutional endorsement or authority to act for another person.
