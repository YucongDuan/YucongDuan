# Yucong Duan · 段玉聪

### DIKWP · Artificial consciousness · Semantic mathematics · Auditable AI

Professor and Doctoral Supervisor, Hainan University  
Chair, World Artificial Consciousness Association (WACA)  
President, World Academy for Artificial Consciousness (WAAC)

I study how **Data, Information, Knowledge, Wisdom and Purpose** can become inspectable, testable and revisable systems. This public research workshop connects semantic foundations with open-source experiments, evidence-led agent governance and practical tools for human capability.

## Reuse, cite and participate

Choose one repository and follow its quick start. Include the version, environment, minimal synthetic input and observed output when reporting an issue. Preserve attribution and check that repository's LICENSE, NOTICE and CITATION.cff. Academic material can be exchanged asynchronously through [ResearchGate](https://www.researchgate.net/profile/Yucong-Duan).

**Make the semantic path visible. Preserve the evidence. Let results guide revision.**
