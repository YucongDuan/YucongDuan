# Collaborate on a concrete research result / 从具体成果开始合作

[Profile](README.md) · [First experiment](START_HERE.md) · [Contribution details](CONTRIBUTING.md)

Choose one question, one repository and one artifact another person can inspect. Independent criticism, negative results and small contributions are welcome.

| Starting task | A useful contribution | Where to submit |
|---|---|---|
| Reproduce PACT | Run the pinned revision in [Start here](START_HERE.md), then provide environment, command and receipt summary | [PACT issues](https://github.com/YucongDuan/DIKWP-PACT-v0.1.0/issues) |
| Challenge a semantic assumption | A MESH² input with competing interpretations and a documented expected conflict | [MESH² issues](https://github.com/YucongDuan/DIKWP-MESH-/issues) |
| Evaluate an evidence decision | A minimal VerityWeave case, expected output and observed output | [VerityWeave issues](https://github.com/YucongDuan/DIKWP-VERITYWEAVE-v2.0.0/issues) |
| Extend a benchmark | A baseline or held-out synthetic case with a stated hypothesis and scoring rule | The target repository's issue or PR |
| Connect two projects | A schema mapping, one successful round trip and one rejected input | The target repositories; identify both revisions |
| Improve research communication | A source correction, accessible example or translation preserving evidence scope | [Profile contribution forms](https://github.com/YucongDuan/YucongDuan/issues/new/choose) |

## Propose a study

Use the [research proposal form](https://github.com/YucongDuan/YucongDuan/issues/new?template=research-proposal.yml) for a public proposal. State the question, prior work, relevant repository, proposed method, your contribution and the intended artifact. A useful artifact might be a reproduction report, test set, adapter, dataset description or paper draft. State what outcome would weaken your hypothesis.

For academic correspondence that should not be public, use [ResearchGate](https://www.researchgate.net/profile/Yucong-Duan). Written proposals make asynchronous review easier. A proposal opens a discussion; it does not reserve supervision, funding or a response date.

## Help readers discover the work

Link to a specific repository or [this introduction](START_HERE.md) when sharing. Name the question it addresses and the result a reader can reproduce. Use [CITING.md](CITING.md) for attribution and [SHARE.md](SHARE.md) for concise introductory text. A report describing what failed is useful research evidence too.

## 中文参与说明

合作可以从一个小问题开始：一次可复现运行、一个反例、一种基线、一个适配器，或一段保持证据含义一致的翻译。请写明具体仓库、提交版本、环境、最小输入、预期结果与实际输出。

公开研究提案请使用[提案表单](https://github.com/YucongDuan/YucongDuan/issues/new?template=research-proposal.yml)，说明研究问题、已有工作、方法、本人可承担的贡献与预期公开材料，并指出什么结果会削弱假设。适合非公开交流的学术材料可通过 ResearchGate 异步沟通。具体代码问题请提交到项目自身的 issue。
