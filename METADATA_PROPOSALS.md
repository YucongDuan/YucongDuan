## Topic policy / 标签原则

Use the current curated research category to suggest three concise topics when no topics exist; retain all existing topic sets. The empty `DIKWP` repository receives only `dikwp` and `research-portfolio`. The repository named `-` contains an ActiveTCM documentation package, so the proposal uses documentation and health-informatics tags rather than relying on its coarse portfolio classification.

The scope wording deliberately distinguishes research packages and prototypes from demonstrated performance. In particular, health and economy descriptions make no claim of clinical benefit, investment return or authorization to act.
