# 段玉聪 · Yucong Duan

### DIKWP · 人工意识 · 语义数学 · 可审计人工智能

海南大学教授、博士生导师 · 世界人工意识科学院（WAAC）院长

以**数据、信息、知识、智慧、目的（DIKWP）**为研究主线，把语义资源及其转化过程落实为可检查、可测试、可修订的系统。这里汇集基础研究、开源实验、智能体治理与面向人的能力发展的应用工具。
