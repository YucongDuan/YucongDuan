# English-first international access update

Date: **8 September 2026**. This update changes how international readers discover, understand and contribute to the research portfolio.

## Published scope

| Surface | Change |
|---|---|
| Public repository descriptions | **80** descriptions translated or edited into English, including 77 entries containing Chinese in the original inventory and three later bilingual descriptions |
| Complete directory | English summaries for **all 483 repositories** across **12 research areas**, with a dedicated [English JSON index](REPOSITORY_SUMMARIES.en.json) |
| Default profile documents | English main profile, research brief, collaboration and citation guidance, shareable introductions, status and transparent-economy comparison |
| Chinese access | Separate reference pages preserve original Chinese or bilingual content, including the twelve category directories |
| Other profile languages | Eleven additional editions continue to link the English and Chinese guides with their target languages identified |
| Contribution interface | English issue forms and PR template, plus a direct link to Chinese contribution guidance |
| Project READMEs | Six English default READMEs with separate Chinese references and clearer source/archive prerequisites |

The [international access guide](INTERNATIONAL_ACCESS.md) connects these entry points. [Exact repository metadata changes](ENGLISH_METADATA_2026-09-08.json) preserve the before-and-after wording.

## Translation and evidence scope

English summaries describe the documented research scope. They retain distinctions among a prototype, a forecast, a proof candidate, a local test record and an externally established result. They do not add runtime verification or institutional adoption claims.

The six README updates preserve the original files in Chinese reference pages. AION and EIR Mesh now identify their expanded source directories before the quick-start steps. ORIGIN, AC-12, CNX-12 and CareerBridge explicitly explain that their delivery archive must be extracted first. Forecast windows retain their original dates.

Packaged applications, datasets, interface messages and historical reports retain their original languages unless the relevant project explicitly states otherwise. This is an internationalization of public entry points and documentation, not a claim that every runtime interface has been localized.

## Verification

The twelve published README files were compared with their local Git blob hashes. All other existing files in those six repositories retained their previous hashes. Default English pages were checked for untranslated Chinese prose outside language-selection controls, issue-form YAML was parsed, and internal links were resolved against the combined profile tree. Repository descriptions were read back from GitHub to verify their exact English text and retained settings.
