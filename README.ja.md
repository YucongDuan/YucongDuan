## 意味資源から検査可能なシステムへ

段玉聡の研究は、Data、Information、Knowledge、Wisdom、Purpose（DIKWP）を、相互に区別されながら変換可能な意味資源として表現します。知識グラフを型付きで計算可能な DIKW／DIKWP グラフへ体系的に拡張し、人工意識、能動医学、意味主権、意味数学、DIKWP ホワイトボックス評価へ接続します。

> 研究ループ：D → I → K → W → P → 行動 → 証拠 → 修正
