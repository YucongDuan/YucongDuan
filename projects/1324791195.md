# Core-Semantic-Federation-and-Continuity-Kernel

[Repository / 仓库](https://github.com/YucongDuan/Core-Semantic-Federation-and-Continuity-Kernel) · [Research area / 研究领域](../directory/dikwp-foundations.md) · [All projects / 全部项目](../REPOSITORY_DIRECTORY.md)

DIKWP-CSFK extends MESH8.0 from semantic birth, post-semantic alias registration, twenty-five core routes, and bidirectional replay inside one subject to explicit semantic co-generation across subjects. It supports human-model, model-model, team-agent, and longitudinal handoffs without introducing a sixth semantic kind
