# Hodge-Conjecture-RBACE-Proof-Package

[Repository / 仓库](https://github.com/YucongDuan/Hodge-Conjecture-RBACE-Proof-Package) · [Research area / 研究领域](../directory/semantic-mathematics.md) · [All projects / 全部项目](../REPOSITORY_DIRECTORY.md)

This package introduces Rational-Balance Algebraic-Cycle Exposure Semantic Closure (RBACE) and gives a complete internal non-traditional proof of the Hodge statement under nine ontological principles. It contains Chinese and English Word reports, a system specification, a reference certificate, and an HTML dashboard.
