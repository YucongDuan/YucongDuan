# Universal-Native-Semantic-Proof-System-v1.0.0

[Repository / 仓库](https://github.com/YucongDuan/Universal-Native-Semantic-Proof-System-v1.0.0) · [Research area / 研究领域](../directory/semantic-mathematics.md) · [All projects / 全部项目](../REPOSITORY_DIRECTORY.md)

D5 is an executable closure kernel in which **D, I, K, W, and P** are the only semantic positions. Proposition, truth, falsity, negation, contradiction, counterexample, set, number, function, axiom, and inference rule are not core primitives. Such content can appear only after it has been explicitly placed in D/I/K/W/P for a particular task.
