# ARCHEQUEST

[Repository / 仓库](https://github.com/YucongDuan/ARCHEQUEST) · [Research area / 研究领域](../directory/dikwp-foundations.md) · [All projects / 全部项目](../REPOSITORY_DIRECTORY.md)

ARCHEQUEST is a deterministic-contract system for classifying and answering 64 recurrent ultimate philosophical questions across 11 local problem worlds. It is compatible with the determinacy firewall and relational-role discipline of DIKWP-MESH 6.2B, while remaining a separately packaged public reference system.
