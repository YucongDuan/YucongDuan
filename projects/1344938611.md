# OmniMemory-OS

[Repository / 仓库](https://github.com/YucongDuan/OmniMemory-OS) · [Research area / 研究领域](../directory/memory-identity.md) · [All projects / 全部项目](../REPOSITORY_DIRECTORY.md)

OmniMemory OS is a local-first memory layer that sits **outside** any single LLM product. It preserves raw conversation evidence, forms reviewable long-term memories, retrieves only task-relevant context, compiles provider-specific memory capsules, and records how memory use affects real outcomes.
