Eighty descriptions were translated or edited for international readers; original descriptions remain in the source metadata and original-language directory pages. The summaries describe the projects' stated research scope. They are not a new audit of all software.

The original inventory contains 459 public descriptions; the remaining entries use labeled editorial summaries. Research categories and related-project links are navigation aids. Programming-language metadata does not identify the language of a user interface.
